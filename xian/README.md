# 斗气苍穹

文字点击类修仙增量游戏（斗破苍穹式境界线）。

## 玩法概要

- **吐纳点击**：点击吸收斗气；购买吐纳/运转功法提升点击与被动。
- **境界九星**：斗之气 → 斗帝共 12 境，每境 1–9 星，满星破境。
- **道途分支**（斗师起抉择）：焚炎 / 炼药 / 霸体 / 魂噬 / 兽契 / 剑心。
- **阵营**（斗皇）：正道 / 黑角域 / 隐世散修。
- **气运抉择**（斗尊）：成帝 / 守界 / 问虚空。
- **多种结局**：按分支、阵营、旗帜与功法匹配，可轮回收集。
- **气运轮回**：重置境界与功法，永久提升产出。
