# 斗气苍穹

文字点击类修仙增量游戏：体系取自凡人修仙，剧情融合斗破 / 凡人 / 遮天 / 仙逆等诸天梗。

## 核心循环

1. **择出身** → 吐纳 / 功法 / 升层破境（炼气→大道）
2. **三槽法宝**：战斗 / 修炼 / 辅助，互不干扰
3. **天才地宝**：战后或机缘获得，直接加灵气 + 本世永久被动
4. **对战**：胜可掉落法宝/地宝；败有低概率身死，否则可能掉段或轻伤
5. **主线剧情**：随机事件池中推进（坊市、秘境、问道等），不全是战斗
6. **随机机缘**：有利有弊；死亡/轮回后按峰值继承
