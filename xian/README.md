# 斗气苍穹

文字点击类修仙增量游戏：体系取自凡人修仙，剧情融合斗破 / 凡人 / 遮天 / 仙逆等诸天梗。

## 核心循环

1. **择出身**（寒门、世家、废柴少爷、穿越者……）获得初始属性与自由点
2. **吐纳点击**攒灵气，修习功法，升层破境（炼气→大道）
3. **剧情抉择**推进道途 / 阵营 / 气运；部分选项含对战，败可身死
4. **法宝**提升属性与战力；可入库，轮回时按峰值境界携带
5. **身死或主动轮回** → 再选出身，继承属性比例与法宝栏位
6. **多结局收集**成就修仙大道

## 属性

攻伐 / 护体 / 身法 / 神识 / 根骨 / 气机 —— 对战按加权战力结算，法宝可加乘区。
